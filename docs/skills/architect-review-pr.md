# `/architect-review-pr`

Adversarial **completeness & wiring** review of a finished feature — the diagnostic pass that runs after `/review-pr`, answering "is this actually done and integrated?" (not "is each line correct?", which is `/code-review` / `/review-pr`). Dispatches ONE fresh-context Claude `Agent` subagent (no `codex` dependency — installs anywhere) that scopes findings to the branch diff vs base (`main`/`master`) but traces the WHOLE repo to confirm reachability, running a fixed 5-type taxonomy (Unwired / Missing / Incomplete / Bug-edge / Risk) behind a mandatory **evidence gate**: no `Unwired`/`Missing` finding is reported without a cited empty-result search proving the gap — else it is downgraded to a question. **Finds first, then fixes CRITICALs** — the subagent is a pure finder that **writes** the ranked report to a caller-supplied path (or `${TMPDIR:-/tmp}/architect-review-pr-<ts>.md`, resolved once at preflight) and the main loop reads that exact path; then the main loop applies a fix for each CRITICAL finding (working tree only, never committed) and re-dispatches a *fresh* reviewer to verify, converging or capping at 3 passes like `/spec-review-codex`. IMPORTANT and below stay report-only; a bare `report-only` token skips the fix loop. Auto-discovers an intent oracle (newest `*-design.md` or `tasks/` plan) best-effort, degrading to code-only. No scripts or templates — the subagent prompt is composed inline in `SKILL.md`.

## Conventions

- `/architect-review-pr` finds, then fixes CRITICALs only — the reviewer subagent never edits (pure finder); the MAIN LOOP applies a fix per CRITICAL between passes and a fresh reviewer verifies, capped at 3 review passes with a contested-finding stop (a fix re-reported verbatim goes to the user, never re-ratcheted). Nothing is ever committed; per-pass reports (`…pass-<N>.md`) stay on disk as the audit trail
- The `report-only` token (stripped from the argument alongside `report-path=`, before scope is read) disables the fix loop — `/ship-it` Step 7 passes it because its conductor owns the Step 6 fix/commit loop and commits nothing after Step 7
- `/architect-review-pr` uses a Claude `Agent` subagent, not `codex` — deliberately no external CLI dependency so it installs anywhere. The subagent is read-only on the repo with exactly one carve-out: it `Write`s its own report to `<REPORT_PATH>`, incrementally, and returns the same markdown only as corroboration
- **The report path is resolved once, before dispatch, and passed in** — a caller-supplied `report-path=<absolute path>` (`/ship-it` Step 7 hands it `report-path=$RUN_DIR/architect-review.md report-only`) or else `${TMPDIR:-/tmp}/architect-review-pr-$(date +%s).md`. The `report-path=` and `report-only` tokens are stripped before anything else in the argument is read as scope, so a report path and a review target can never be confused. The main loop reads that exact variable. It must **never** glob `architect-review-pr-*.md`, and must never write the report from the subagent's return message: a subagent that completes its review then idles sends no final message, so writing "what was received" yields no report at all, while globbing silently adopts a stale report from another session on another branch. Missing file ⇒ say so and stop; never re-dispatch or re-ask (a re-ask has never recovered a lost hand-off)
- Same rationale as ship-it's contract-as-file, and the pattern `review-codebase` has always used (its audits write to `docs/audits/` and return a summary)
- `/architect-review-pr`'s evidence gate is the quality lever: no `Unwired`/`Missing` finding ships without a cited empty-result search (callers, string-keyed dispatch, DI/decorator, barrel re-exports, dynamic dispatch, config/CI/manifest) proving the gap — an uncited claim is downgraded to a question, not reported
- `/architect-review-pr` scopes FINDINGS to the branch diff vs base but traces the WHOLE repo for reachability — a diff-only review can't distinguish "created but not wired" from "wired elsewhere"; an explicit file/dir/feature argument overrides diff scoping, and no-diff-no-argument is the only blocking question
